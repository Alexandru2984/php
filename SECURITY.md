# Security policy

## Supported version

Only the latest deployed revision of `main` receives security fixes. Historical
revisions and unmerged feature branches are unsupported.

## Reporting a vulnerability

Do not open a public issue with exploit details, credentials, personal data or live
attack evidence. Use the repository's private
[security advisory form](https://github.com/Alexandru2984/php/security/advisories/new).

Include the affected URL/component, impact, minimal reproduction, required access and
any evidence already collected. Do not access other users' data, persist access,
degrade production, run automated high-volume scanning or perform social engineering.

The initial target is an acknowledgement within 72 hours. Remediation and disclosure
timing depend on severity and safe rollout requirements. This target is not a bug
bounty or authorization to test outside this application.
